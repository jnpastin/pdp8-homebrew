
## Memory

### Purpose
Defines memory interaction model.

### Model
- Memory accessed via MA (address) and MDB (data)
- Data captured into MB for CPU use

### Operations
- Read: memory drives MDB, MB captures
- Write: MB drives MDB, memory captures
