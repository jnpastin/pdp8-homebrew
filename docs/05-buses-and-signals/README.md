
## Buses and Signals

### Purpose
Defines system interconnects, signal classifications, and usage rules.

### Model
- Buses are transient transport mechanisms
- Registers hold stable state

### Key Concepts
- Ownership: who drives a signal
- Validity: when a signal is meaningful
