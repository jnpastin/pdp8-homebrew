# Internal Control Signals

## Purpose

Defines the complete set of microarchitectural control signals used to drive
CPU datapath behavior.

This document is the authoritative source for:
- signal definitions
- signal semantics
- constraints on signal usage

See:
- [Control Model](../04-control/01-control-model.md)
- [Control Constraints](../04-control/03-control-constraints.md)
- [Micro-Operations](../03-microarchitecture/02-micro-operations.md)

---

## 1. Scope

Internal control signals:

- are generated by the control store
- directly control CPU datapath behavior
- are local to the CPU
- are not visible outside the CPU

They implement μops.

---

## 2. Global Signal Properties

### Polarity

All control signals are active-high unless otherwise specified.

---

### Timing

- signals are evaluated during TS
- effects occur only at TP

Defined in:
- [Control Model](../04-control/01-control-model.md)

---

## 3. Data Path Control

### Data Path Constraints

- DB_src must be valid before TP
- destination registers must see stable inputs at TP
- exactly one DB_src must be active

---

### DB_src

**Description**  
Selects the source driving the internal data path.

**Type**  
encoded field

**Width**  
4 bits

**Encoding**

0x0 → AC  
0x1 → PC  
0x2 → MB  
0x3 → MQ  
0x4 → SR  
0x5 → EA  
0x6 → IR  
0x7 → ALU  
0x8 → MDB_input  
0x9 → DB_input  
0xA → CONST_0  
0xB–0xF → reserved  

**Used By**

- [AC_TO_MB](../03-microarchitecture/02-micro-operations.md#ac_to_mb)  
- [PC_TO_MB](../03-microarchitecture/02-micro-operations.md#pc_to_mb)  
- [MB_TO_IR](../03-microarchitecture/02-micro-operations.md#mb_to_ir)  
- [MB_TO_EA](../03-microarchitecture/02-micro-operations.md#mb_to_ea)  
- [MEM_READ_TO_MB](../03-microarchitecture/02-micro-operations.md#mem_read_to_mb)  
- [MEM_WRITE_FROM_MB](../03-microarchitecture/02-micro-operations.md#mem_write_from_mb)  
- all arithmetic and logical μops  

**Constraints**

- exactly one source selected  
- MDB_input and DB_input validity defined externally  

See:  
- [Bus System](../05-buses-and-signals/README.md)

---

## 4. Address Path Control

### Address Path Constraints

- AB_src must be valid before MA_load at TP
- MA must contain a valid address before RD/WR

---

### AB_src

**Description**  
Selects the source driving the address bus.

**Type**  
encoded field

**Width**  
2 bits

**Encoding**

00 → PC  
01 → EA  
10 → CONST_0  
11 → reserved  

**Used By**

- [PC_TO_MA](../03-microarchitecture/02-micro-operations.md#pc_to_ma)  
- [EA_TO_MA](../03-microarchitecture/02-micro-operations.md#ea_to_ma)  
- [MA_CLEAR](../03-microarchitecture/02-micro-operations.md#ma_clear)  

**Constraints**

- feeds MA only (no bypass)

## 6. ALU Control

### ALU Constraints

- ALU output must be stable before TP
- L updates occur only via ALU

---

### ALU_op

**Description**  
Selects ALU operation.

**Type**  
encoded field  

**Width**  
4 bits  

**Encoding**

0x0 → PASS  
0x1 → ADD  
0x2 → AND  
0x3 → OR  
0x4 → NOT  
0x5 → INC  
0x6 → ROR  
0x7 → ROL  
0x8 → RTR  
0x9 → RTL  
0xA → BSW  
0xB–0xF → reserved  

**Used By**

- [ADD_AC_MB](../03-microarchitecture/02-micro-operations.md#add_ac_mb)  
- [AC_AND_MB](../03-microarchitecture/02-micro-operations.md#ac_and_mb)  
- [AC_OR_MQ](../03-microarchitecture/02-micro-operations.md#ac_or_mq_INC](../03-microarchitecture/02-micro-operations.md#ac_inc)  
- [MB_INC](../03-microarchitecture/02-micro-operations.md#mb_inc)  
- rotate and swap μops  

---

### ALU_A_src

**Type**  
encoded field  

**Width**  
1 bit  

**Encoding**

0 → AC  
1 → MB  

**Used By**

- [ADD_AC_MB](../03-microarchitecture/02-micro-operations.md#add_ac_mb)  
- [AC_INC](../03-microarchitecture/02-micro-operations.md#ac_inc)  
- [MB_INC](../03-microarchitecture/02-micro-operations.md#mb_inc)  

---

### ALU_B_src

**Type**  
encoded field  

**Width**  
3 bits  

**Encoding**

0x0 → NONE  
0x1 → MB  
0x2 → MQ  
0x3 → SR  
0x4 → CONST_1  
0x5–0x7 → reserved  

**Used By**

- [ADD_AC_MB](../03-microarchitecture/02-micro-operations.md#add_ac_mb)  
- [AC_AND_MB](../03-microarchitecture/02-micro-operations.md#ac_and_mb)  
- [AC_OR_MQ](../03-microarchitecture/02-micro-operations.md#ac_or_mq)  
- [AC_OR_SR](../03-microarchitecture/02-micro-operations.md#ac_or_sr)  

---

### Link Handling

Handled exclusively within the ALU.

Used By:
- addition
- increment
- rotate operations

- address generation  
- ALU operations
